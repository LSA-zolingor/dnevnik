# Дневник райдера

Приложение-дневник прогресса для посетителей: беговел, батут, самокат, ролики, BMX, вейкборд, мотокросс.
Золинский парк · Выше головы · Бронекаска · Ракета (Зеленогорск).

Устанавливается на телефон как приложение (PWA), работает без интернета, прогресс отправляется в Google Таблицу.
При обновлении `index.html` поменяйте `VERSION` в `sw.js`, чтобы телефоны получили новую версию.
